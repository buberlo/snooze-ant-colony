# Snooze Ant Colony

> Every snoozed alarm raises an ant that demands breakfast.

A mobile alarm companion where missed and snoozed alarms hatch tiny ants in a virtual hill. The twist is that the colony files for breakfast tax and can cover your lock screen with ant stickers until you feed it.

## Features
- Convert every snoozed or missed alarm into a local ant population
- Feed ants by logging walks, stretching, or closing apps before bed
- Trigger a lock-screen tax notification if the colony grows past a threshold
- Export a weekly colony ledger with alarm hygiene stats

## Stack
- React Native
- Expo
- SQLite
- Lottie

## Getting started
```
npm install && npx expo start
```
